A package for CometEngine

Animation that fits on one line.

Tweeny moves any value over time — positions, rotations, scales, colours, alpha, UI, audio, or a number of your own. It handles the easing, the looping, the sequencing and the cleanup, so animation stops being something you hand-roll in Update.

It is a package for CometEngine, written in AngelScript.

    .SetEase(Ease::OutBack)
    .SetLoops(-1, LoopType::Yoyo);

Install

Get Tweeny from the CometEngine marketplace, or clone the repository and copy Packages/tweeny into your project.

Importing it is the whole setup: there is no manager prefab to place, no script to register and no initialisation call. Tweeny registers itself through a project setting, so the engine creates its runner at play start the moment the package is present.

Open Project Settings › TweenySettings to change the defaults — easing curve, loop type, auto-kill, auto-play, global time scale and logging.

Seeing it run

The repository is a working CometEngine project with eleven demo scenes. Open it and press Play on 00_Bootstrap: the tour walks itself through all of them and loops back to the start, so one Play shows easings, loops, sequences, punch and shake, jumps, paths, shortcuts, playback control, coroutines, the no-code component, and a stress test running four hundred simultaneous tweens.

It also carries the test suite — just under five hundred checks across ten suites, which run themselves whenever the project compiles.
